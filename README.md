# My Vibecoding Prompts List

Una recopilación de prompts listos para usar en proyectos de **vibecoding** — desarrollo web rápido e iterativo asistido por IA. Cada prompt describe un efecto visual, componente o patrón de UI con suficiente detalle técnico para que una IA (o tú mismo) lo implemente directamente.

## Estructura

```
diseño web prompts/     → Efectos visuales y componentes para la web
```

## Cómo usar

Cada archivo `.md` dentro de las carpetas es un prompt autocontenido. Cópialo y pégalo directamente en tu herramienta de IA favorita (Claude, Cursor, v0, etc.) para generar el código.
