Create a `'use client'` React component called `ScannerReveal` that implements a cursor-driven scanner reveal effect. An overlay image (PNG line art or illustration with a white or transparent background, placed at `public/images/overlay.png`) is invisibly layered on top of a full-viewport background image. When the user moves the mouse over the container, a circular spotlight opens around the cursor and reveals the overlay within that radius; when the mouse leaves, the spotlight closes. The revealed artwork is color-tinted and has a soft bloom glow. Use the HTML5 Canvas 2D API for rendering and GSAP 3 to animate the spotlight radius.

The component mounts a `<canvas>` absolutely positioned over its parent container (`pointer-events: none; z-index: 16`) and reads `canvas.parentElement` to size itself and attach mouse listeners — no props needed. The parent container must have `position: relative; overflow: hidden`.

On overlay image load (and whenever the container resizes via ResizeObserver), preprocess two offscreen canvases. Scale the image using the same formula as CSS `background-size: cover`: `scale = Math.max(canvasW / img.naturalWidth, canvasH / img.naturalHeight)`, centered with `offsetX = (canvasW - img.naturalWidth * scale) / 2` and `offsetY = (canvasH - img.naturalHeight * scale) / 2`. For the first canvas (sharp layer), iterate every pixel: compute `lum = 0.299*R + 0.587*G + 0.114*B`, then `darkness = 255 - lum`; if `darkness < 20` set alpha to 0 to remove near-white background; otherwise apply a gold tint (`R = min(255, R*1.25+35)`, `G = min(255, G*1.05+5)`, `B = max(0, B*0.25)`) and set `A = min(255, darkness * 2.8)`. For the second canvas (glow layer), draw the sharp canvas into it with `ctx.filter = 'blur(8px)'`.

In the rAF loop, clear the canvas and if radius `r > 0.5`: draw the glow layer at 55% opacity, then the sharp layer at 100% opacity, then apply a circular reveal mask using `destination-in` compositing with `createRadialGradient(x, y, 0, x, y, r)` and color stops at `0→rgba(0,0,0,1)`, `0.7→rgba(0,0,0,0.95)`, `1→rgba(0,0,0,0)`. Restore `globalCompositeOperation = 'source-over'`.

For mouse interaction, use a `useRef({ x: 0, y: 0, r: 0 })` that the rAF loop reads directly — no React re-renders. On `onMouseMove`, update `x` and `y` and animate `r` toward `SPOT_R` with `gsap.to(spot, { r: SPOT_R, duration: 0.38, ease: 'power2.out' })`. On `onMouseLeave`, animate `r` back to `0` with `duration: 0.55, ease: 'power2.in'`. Always call `gsap.killTweensOf` before each animation.

Default constants: `SPOT_R = 160` (spotlight radius in px), bloom opacity `0.55`, blur `8px`, darkness threshold `20`, line opacity multiplier `2.8`.
