Crea un componente React `'use client'` llamado `ScannerReveal` que implemente un efecto de escáner con revelado por cursor. El efecto consiste en una imagen overlay (PNG de dibujo o ilustración con fondo blanco o transparente, ubicada en `public/images/overlay.png`) superpuesta invisiblemente sobre una imagen de fondo a pantalla completa. Cuando el usuario mueve el ratón sobre el contenedor, se abre un foco circular alrededor del cursor que revela el overlay dentro de ese radio; al salir, el foco se cierra. La imagen revelada tiene un tinte de color y un suave resplandor (bloom). Usa HTML5 Canvas 2D para el renderizado y GSAP 3 para animar el radio del foco.

El componente monta un `<canvas>` posicionado absolutamente sobre el contenedor padre (`pointer-events: none; z-index: 16`) y lee `canvas.parentElement` para dimensionarse y adjuntar los listeners de ratón, sin necesitar props. El contenedor padre debe tener `position: relative; overflow: hidden`.

Al cargar la imagen overlay (y cada vez que el contenedor cambie de tamaño vía ResizeObserver), preprocesa dos canvas offscreen. Escala la imagen con la misma fórmula de CSS `background-size: cover`: `scale = Math.max(canvasW / img.naturalWidth, canvasH / img.naturalHeight)`, centrando con `offsetX = (canvasW - img.naturalWidth * scale) / 2` y `offsetY = (canvasH - img.naturalHeight * scale) / 2`. En el primer canvas (capa nítida), itera cada píxel: calcula `lum = 0.299*R + 0.587*G + 0.114*B`, luego `darkness = 255 - lum`; si `darkness < 20` pone alpha en 0 para eliminar el fondo blanco; si no, aplica el tinte dorado (`R = min(255, R*1.25+35)`, `G = min(255, G*1.05+5)`, `B = max(0, B*0.25)`) y `A = min(255, darkness * 2.8)`. En el segundo canvas (capa de resplandor), dibuja la capa nítida con `ctx.filter = 'blur(8px)'`.

En el bucle rAF, limpia el canvas y si el radio `r > 0.5`: dibuja la capa de resplandor al 55% de opacidad, luego la capa nítida al 100%, y finalmente aplica la máscara circular con `destination-in` usando un `createRadialGradient(x, y, 0, x, y, r)` con paradas en `0→rgba(0,0,0,1)`, `0.7→rgba(0,0,0,0.95)` y `1→rgba(0,0,0,0)`. Restaura `globalCompositeOperation = 'source-over'`.

Para la interacción, usa un `useRef({ x: 0, y: 0, r: 0 })` que el rAF lee directamente sin re-renders. En `onMouseMove` actualiza `x` e `y` y anima `r` hacia `SPOT_R` con `gsap.to(spot, { r: SPOT_R, duration: 0.38, ease: 'power2.out' })`. En `onMouseLeave` anima `r` de vuelta a `0` con `duration: 0.55, ease: 'power2.in'`. Usa `gsap.killTweensOf` antes de cada animación.

Constantes por defecto: `SPOT_R = 160` (radio del foco en px), bloom al `0.55` de opacidad, blur de `8px`, umbral de darkness en `20`, multiplicador de opacidad de líneas en `2.8`.
